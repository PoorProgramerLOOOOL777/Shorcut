🌐 Dynamic Island for Windows

Una isla dinámica para Windows, personalizada completamente a tu gusto.

Transforma tu escritorio de Windows con una isla dinámica inspirada en las interfaces modernas. Este proyecto utiliza PowerShell para ofrecer una experiencia personalizable, ligera y práctica desde un acceso directo (Shortcut).

⸻

✨ Características

* 🎨 Personalización visual: adapta la apariencia de la isla a tu estilo.
* 🖥️ Integración con Windows: diseñada para funcionar desde un acceso directo.
* ⚡ PowerShell: ejecuta la experiencia sin necesitar una aplicación tradicional.
* 🧩 Diseño configurable: permite adaptar diferentes elementos visuales.
* 🔧 Configuración personalizada: ajusta la experiencia según tus preferencias.

🚀 Instalación

1. Descarga o clona este repositorio.
2. Extrae los archivos en una carpeta de tu preferencia.
3. Localiza el acceso directo de la Dynamic Island.
4. Configura las opciones disponibles.
5. Ejecuta el acceso directo y disfruta de tu nueva interfaz.

⚙️ Requisitos

* Windows 10 o Windows 11.
* Windows PowerShell.
* Permisos para ejecutar scripts de PowerShell según la configuración del sistema.

🎨 Personalización

La idea principal del proyecto es que cada usuario pueda adaptar su isla dinámica.

Algunas ideas de personalización:

* Colores y transparencias.
* Tamaño y posición.
* Elementos visuales.
* Información mostrada.
* Apariencia general.

Las opciones disponibles dependerán de la versión del proyecto.

🛠️ Tecnologías

* PowerShell

* Shortcuts (.lnk)
